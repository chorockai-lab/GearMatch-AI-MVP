> 대상: iPhone Safari · Android Chrome · 카카오톡 인앱 브라우저(iOS·Android)

결과 칸에는 **정상 / 오류 / 미검증** 중 하나를 적고, 오류는 메모에 화면 캡처 파일명을 남깁니다.

## 0-1. iPhone Safari 우선 확인 (캐릭터 v2 적용 후 · 약 25분)

전체 표(§2-A)를 다 하기 전에 아래를 먼저 확인합니다. 각 단계의 ID는 §1 상세 항목입니다.

**새 캐릭터 기준** — 러너: 적갈색 머리 · 흰 티 · 차콜 쇼츠 · 라임 러닝화. 동물은 러너보다 작게 오른쪽 위 레인에 표시. 고양이는 검정·흰색 턱시도.

**지켜야 할 것** — 기존 사용자가 있는 브라우저에서는 **사이트 데이터 삭제 · 테스트 다시 하기 · 기록 수정/삭제를 하지 않습니다.** 신규 온보딩은 반드시 별도 환경에서 합니다.

### A. 기존 Safari 사용자 (지금 쓰는 Safari 그대로 · 데이터 변경 없음)

| 순서 | 할 일 | 기대 결과 | 우선 항목 |
|---|---|---|---|
| A-1 | 열기 전에 기억나는 내 동물·최근 기록·신발을 메모 → 주소 A(`/?qa=1`) 열기 | 랜딩 없이 RUNNING, 메모와 같은 동물·기록·신발 (R-1) | ① 기존 데이터 |
| A-2 | RUNNING 화면 확인 | 러너·동물이 **새 그림**으로 바뀜, 서로 겹치지 않고 선명, 기록이 있으면 달리는 모습 | ② 캐릭터 |
| A-3 | `VIEW STATS` | 예전 기록 수·거리 그대로 (D-4) | ① 기존 데이터 |
| A-4 | (기록 추가를 원할 때만) `오늘의 러닝 남기기` → 저장 | 새 기록이 추가되고 예전 기록은 그대로. 원하지 않으면 B-4에서 확인 | ③ 기록 저장 |
| A-5 | `이미지 저장` → 공유 시트에서 `취소` → 다시 `이미지 저장` → **이미지 저장** | 취소 시 문구 없음 → 저장 후 "공유 창에서 선택한 작업을 마쳤어요…" → **사진 앱**에 세로로 긴 PNG (C-1·C-5·C-6) | ④ 사진 앱 |
| A-6 | 사진 앱에서 이미지 확대 | 화면 카드와 같은 내용, 새 캐릭터 선명, 아래 `GEARMATCH`, DEMO 표기 없음 (C-2) | ④ 사진 앱 |

이 Safari에서 배포 전에 온보딩을 마친 적이 없다면(A-1에서 랜딩이 보이면) **여기서 테스트를 시작하지 말고** A를 "미검증 — 기존 데이터 없음"으로 적고 B로 갑니다.

### B. 신규 온보딩 (기존 세션과 분리된 환경)

환경은 둘 중 하나를 고르고 표에 적습니다.
- **권장: Safari 프로필 'QA'** (iOS 17 이상) — 설정 → 앱 → Safari → **새로운 프로필** → 'QA'. Safari 탭 화면에서 프로필을 'QA'로 바꿔 진행. 저장 공간이 기존 프로필과 분리되고 유지되므로 재방문(B-5)까지 확인 가능
- 대안: **개인정보 보호 브라우징 탭** — 탭을 닫으면 데이터가 지워지므로 B-5는 **같은 탭에서 주소를 다시 입력**해 확인(탭을 닫은 뒤 새로 시작되는 것은 정상)

| 순서 | 할 일 | 기대 결과 | 우선 항목 |
|---|---|---|---|
| B-1 | 분리 환경에서 주소 A(`/?qa=1`) | 확정 랜딩 이미지가 보임 = 최초 방문 (F-1). RUNNING이 보이면 분리되지 않은 것 → 중단하고 환경 확인 | — |
| B-2 | 테스트 Q1~Q5 → Reveal | 내 동물이 새 그림으로 크게(×5) 선명하게, 점수·퍼센트 없음 (O-1·O-2) | ② 캐릭터 |
| B-3 | `내 Runner 완성하기` → 습관 3개 → 건너뛰기 → 신발 선택 → 완성 | RUNNING: 서 있는 러너 + 내 동물, 겹치지 않음 (O-3~O-6) | ② 캐릭터 |
| B-4 | `오늘의 러닝 남기기` → 거리 5.3 · 시간 31:20 → 저장 | TODAY'S RUN 5.3KM · 5'55" · 31:20, 달리는 모습으로 바뀜, 키보드가 버튼을 가리지 않음 (D-1·D-2) | ③ 기록 저장 |
| B-5 | 재방문: QA 프로필은 탭을 닫고 `/` 다시 열기, 개인정보 보호 탭은 같은 탭에서 `/` 다시 입력 | RUNNING으로 바로 이동, 동물·기록·신발 유지 (R-1) | ① 데이터 유지 |
| B-6 | (A-5를 못 했으면) `이미지 저장` → 사진 앱 확인 | A-5·A-6과 같음 | ④ 사진 앱 |

## 0-2. Android 우선 확인 (Android Chrome · 삼성 인터넷 · Android 카카오톡 인앱)

§0-1과 같은 원칙: **기존 사용자가 있는 브라우저는 데이터 변경 없이 유지만 확인**, 신규 온보딩은 그 브라우저에 기록이 없을 때(첫 화면이 랜딩)만 진행합니다. 첫 화면이 RUNNING이면 기존 세션 → 유지 확인만.
신규 환경이 필요하면: Chrome **시크릿 탭** · 삼성 인터넷 **비밀 모드**(탭을 닫으면 지워지므로 재접속은 같은 탭에서 주소 재입력).

| 확인 항목 | 할 일 | 기대 결과 | Chrome | 삼성 인터넷 | 카톡 인앱 |
|---|---|---|---|---|---|
| 온보딩·동물 결과 | 주소 A(`/?qa=1`) → 테스트 → Reveal → 온보딩 완료 (O-1~O-6) | 새 그림 동물 Reveal(×5), RUNNING에 러너+동물 | | | |
| 러닝 기록 저장 | 거리 5.3 · 31:20 저장 (D-1·D-2) | 5.3KM · 5'55", 달리는 모습, 숫자 키패드가 버튼을 가리지 않음 | | | |
| 이미지 저장 | `이미지 저장` (C-1·C-2·C-8) | Chrome·삼성 인터넷: **바로 다운로드** + "다운로드를 시작했어요…" → '내 파일 › 다운로드'·갤러리에 `gearmatch-runner-card-날짜.png`. 카톡 인앱: **미리보기 + 길게 눌러 저장** | | | |
| 재접속 데이터 유지 | 브라우저(앱)를 완전히 닫고 같은 주소 다시 열기 (R-1, 카톡은 S-4) | RUNNING으로 바로, 동물·기록·신발 유지 | | | |
| 캐릭터·화면 표시 | RUNNING·Stats·Reveal, 화면 크기 최대로 키워 좁은 폭(L-1~L-3) | 러너·동물 겹침·번짐 없음, 하단 탭이 내비게이션 바에 가리지 않음 | | | |
| 브라우저 간 분리 | 세 환경을 오가며 첫 화면 확인 (S-3) | 각자 따로 시작 = **정상(기존 한계)** | | | |

삼성 인터넷은 '다운로드' 표시줄이나 알림으로 저장 위치를 알려 줍니다. 파일이 어디에도 없으면 주요 오류(§3).
세션이 사라졌을 때는 §0-1 C의 "오류 vs 저장소 초기화" 기준을 그대로 씁니다(카카오톡 캐시 삭제·앱 재설치, 브라우저 데이터 삭제, 저장 공간 부족, 다른 주소).

## 3. 판정 기준

### 테스트 완료 기준
- 3개 환경(iPhone Safari · Android Chrome · 카카오톡 인앱 1종 이상)에서 F·O·R·D·C 전 항목에 결과가 기록됨(미검증은 사유 기재)
- **치명적 오류 0건**, 주요 오류는 별도 Issue로 등록되고 수정 여부 결정됨
- S 항목은 "기존 한계"로 기록(오류 집계에서 제외), 단 S-4는 오류 대상
- QA 시간대와 사용한 주소를 기록해 분석 제외 가능

### 치명적 오류 — 외부 사용자 테스트 중단 (하나라도 있으면 진행하지 않음)
1. **같은 브라우저에서 기록이 사라짐**: R-1·R-4·S-4에서 새 사용자로 시작하거나 동물·기록이 비어 있음
2. **주 여정 막힘**: 테스트·온보딩·기록 저장 중 진행 불가, 흰 화면, 무한 로딩, "다시 시도"로 회복 안 됨
3. **잘못된 숫자**: Stats·카드 이미지의 거리·페이스·시간이 입력한 기록과 다름, 기록 0건인데 수치 표시
4. **개인정보 노출**: 이미지·화면·주소에 키·체중·발 사이즈·이메일·사용자 ID가 보임
5. **거짓 성공 표시**: 공유·저장이 안 됐는데 "완료"로 표시, 취소를 오류로 표시
6. **버튼에 닿을 수 없음**: 주요 버튼(테스트 시작·다음·저장)이 키보드·하단 탭·홈 바에 가려져 누를 수 없음

### 주요 오류 — 내부 테스트는 계속, 외부 전 수정 검토
- 320폭에서 글자 겹침·잘림, 이미지 흐림, 한글 깨짐
- 카카오톡 인앱에서 길게 눌러 저장 불가(대안 안내가 있으면 주요, 없으면 치명)
- 다운로드 파일이 어디에도 보이지 않음(공유 → 사진 저장이 되면 주요)
