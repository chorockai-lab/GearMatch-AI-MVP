## 화면에 들어갈 안내문 (초안)

### GearMatch 개인정보 수집·이용 안내

GearMatch는 로그인 없이 쓰는 러닝 서비스입니다. 이름·이메일·전화번호·위치(GPS)는 받지 않습니다.
이 안내는 서비스가 저장하는 정보와 그 이유를 설명합니다.

**1. 저장하는 정보**

| 구분 | 항목 | 필수/선택 | 언제 |
|---|---|---|---|
| 이용자 구분 | 무작위로 만들어지는 익명 ID | 자동 | 처음 방문할 때 |
| 러닝 테스트 | 5문항 답변, 러닝 동물 결과 | 필수 | 테스트를 마칠 때 |
| 러닝 습관 | 러닝 경험, 주간 러닝 횟수, 한 번에 뛰는 거리 / 주간 총 거리 | 필수 3개 / 선택 1개 | 프로필 1단계 |
| 신체 정보 | 키, 체중, 발 사이즈, 관심 거리 | **선택** (건너뛰기 가능) | 프로필 2단계 |
| 신발 | 지금 신는 러닝화 이름, 관심 신발로 저장한 제품 | 선택 | 신발 선택·저장할 때 |
| 러닝 기록 | 날짜, 거리, 시간, 그때 신은 신발 | 기록할 때만 | 러닝을 저장할 때 |
| 이용 기록 | 화면 방문·버튼 사용 같은 이용 이벤트, 화면 주소, 발생 시각 (답변 내용·키·체중은 이벤트에 넣지 않음) | 자동 | 서비스를 쓰는 동안 |
| 접속 정보 | IP 주소, 브라우저 종류 등 접속 기록 | 자동 | 인증·호스팅 서비스가 보안을 위해 남김 |

- 카드 이미지(이미지 저장)는 **이용자의 기기에서 만들어지며** 서버로 보내지 않습니다.
- 브라우저 저장 공간에는 로그인 상태 유지용 정보와 서비스 설정이 저장됩니다. 브라우저 데이터를 지우면 이 기기에서는 기록을 다시 불러올 수 없습니다.

**2. 이용 목적**
- 러닝 동물 결과와 내 러닝 기록·통계 보여 주기
- 비슷한 신체 조건 러너의 신발 정보 보여 주기(ITEMS) — 키·체중·발 사이즈를 입력한 경우에만
- 서비스 개선을 위한 이용 통계(단계별 완료율 등) — 개인을 식별하지 않는 집계로만 사용

**3. 보관 기간 [결정 필요]**
- 안 A: 테스트 기간 종료 후 ○개월이 지나면 전체 삭제
- 안 B: 마지막 이용 후 1년이 지나면 삭제
- 접속 기록(IP 등)은 각 서비스 제공 회사의 보관 정책을 따름 [법무 확인]

**4. 삭제 요청 방법 [결정 필요]**
- 서비스 안에는 아직 "내 데이터 삭제" 기능이 없습니다. 삭제를 원하면 아래 담당자에게 연락해 주세요.
- 로그인이 없으므로 본인 확인 방법이 필요합니다: 예) 참여 기간, 러닝 동물 결과, 최근 러닝 기록(날짜·거리)으로 확인 후 삭제 [결정 필요]
- 브라우저 데이터를 지우는 것만으로는 서버의 기록이 삭제되지 않습니다.

**5. 처리를 맡기는 회사 (처리 위탁 · 국외 이전) [법무 확인]**

| 회사 | 맡기는 일 | 저장 위치 |
|---|---|---|
| Supabase Inc. | 데이터 저장·익명 로그인 | 서울 리전(대시보드에서 확인 필요) — 회사 소재지 미국 |
| Vercel Inc. | 웹사이트 호스팅·접속 기록 | 미국 등 |
| PostHog Inc. | 이용 통계 분석 | 미국 (`us.i.posthog.com`) — **현재는 내부 테스트 데이터만 전송, 외부 참여자 데이터는 전송하지 않음** |

**6. 이용자의 권리**
- 저장된 정보의 열람·정정·삭제·처리 정지를 요청할 수 있습니다. 러닝 기록은 앱에서 직접 수정·삭제할 수 있습니다.
