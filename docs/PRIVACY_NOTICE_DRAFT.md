## 화면에 들어갈 안내문 (초안)

### GearMatch 개인정보 처리 안내

초록소프트(ChoRockSoft)가 운영하는 GearMatch는 로그인 없이 쓰는 러닝 서비스입니다. 이름·이메일·전화번호·위치(GPS)는 받지 않습니다.
이 안내는 서비스가 저장하는 정보와 그 이유, 삭제 방법을 설명합니다.

**1. 저장하는 정보**

| 구분 | 항목 | 필수/선택 | 언제 |
|---|---|---|---|
| 이용자 구분 | 무작위로 만들어지는 익명 ID | 자동 | 처음 방문할 때 |
| 러닝 테스트 | 5문항 답변, 러닝 동물 결과 | 필수 | 테스트를 마칠 때 |
| 러닝 습관 | 러닝 경험, 주간 러닝 횟수, 한 번에 뛰는 거리 / 주간 총 거리 | 필수 3개 / 선택 1개 | 프로필 1단계 |
| 신체 정보 | 키, 체중, 발 사이즈, 관심 거리 | **선택** (건너뛰기 가능) | 프로필 2단계 |
| 신발 | 지금 신는 러닝화 이름, 관심 신발로 저장한 제품 | 선택 | 신발 선택·저장할 때 |
| 러닝 기록 | 날짜, 거리, 시간, 그때 신은 신발 | 기록할 때만 | 러닝을 저장할 때 |
| 이용 기록 | 화면 방문·버튼 사용 같은 이용 이벤트, 화면 주소, 발생 시각 (답변 내용·키·체중은 이벤트에 넣지 않음) | 자동 | 서비스를 쓰는 동안 |
| 접속 정보 | IP 주소, 브라우저 종류 등 접속 기록 | 자동 | 인증·호스팅 서비스가 보안·운영을 위해 남김 |

- 카드 이미지(이미지 저장)는 **이용자의 기기에서 만들어지며** 서버로 보내지 않습니다.
- 브라우저 저장 공간에는 익명 로그인 상태와 서비스 설정이 저장됩니다.

**2. 이용 목적과 처리 근거** [법무 검토 — 항목별 근거 확정 전]
- 러닝 동물 결과와 내 러닝 기록·통계 보여 주기
- 비슷한 신체 조건 러너의 신발 정보 보여 주기(ITEMS) — 키·체중·발 사이즈를 입력한 경우에만
- 서비스 개선을 위한 이용 통계(단계별 완료율 등) — 개인을 식별하지 않는 집계로 사용

**3. 보관 기간**
- 외부 테스트 종료일([값 대기])로부터 **3개월** 동안 보관한 뒤 삭제합니다.
- 법령에 따라 따로 보관해야 하는 정보가 있으면 그 기간을 따릅니다. [법무 검토]
- 서비스 제공 회사의 접속 기록·백업은 각 회사의 보관 정책에 따라 일정 기간 남을 수 있습니다. [확인 필요 — 회사별 기간]

**4. 삭제 방법**
- **앱 안에서 바로 삭제**: '개인정보 처리 안내' 화면의 `내 데이터 삭제` → 확인 → 삭제. 지금 이 브라우저(앱)에서 쓰는 익명 계정과 그 계정의 테스트 결과·러닝 습관·신체 정보·신발·러닝 기록·이용 기록이 모두 삭제되며 되돌릴 수 없습니다.
- **이메일 문의**: [공식 이메일 — 값 대기]. 로그인이 없는 서비스라 다른 사람의 정보로는 본인을 확인할 수 없습니다. 이메일로는 삭제 방법을 안내하며, 실제 삭제는 데이터를 만든 브라우저(앱)에서 `내 데이터 삭제`로 진행합니다. 그 브라우저를 더 이상 쓸 수 없는 경우 데이터는 3번의 보관 기간이 끝날 때 함께 삭제됩니다.
- 브라우저 데이터만 지우면 이 기기에서 기록을 불러올 수 없게 될 뿐, 서버의 기록은 삭제되지 않습니다.

**5. 처리를 맡기는 회사와 국외 이전** [확인 필요 · 법무 검토]
