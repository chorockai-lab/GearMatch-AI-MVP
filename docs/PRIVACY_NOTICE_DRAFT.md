## 화면에 들어갈 안내문 (초안)

### GearMatch 개인정보 수집·이용 안내

초록소프트(ChoRockSoft)가 운영하는 GearMatch는 로그인 없이 쓰는 러닝 서비스입니다. 이름·이메일·전화번호·위치(GPS)는 받지 않습니다.
이 안내는 서비스가 저장하는 정보와 그 이유, 삭제 방법을 설명합니다.

**1. 저장하는 정보**

| 구분 | 항목 | 필수/선택 | 언제 |
|---|---|---|---|
| 이용자 구분 | 무작위로 만들어지는 익명 ID | 자동 | 처음 방문할 때 |
| 러닝 테스트 | 5문항 답변, 러닝 동물 결과 | 필수 | 테스트를 마칠 때 |
| 러닝 습관 | 러닝 경험, 주간 러닝 횟수, 한 번에 뛰는 거리 / 주간 총 거리 | 필수 3개 / 선택 1개 | 프로필 1단계 |
| 신체 정보 | 키, 체중, 발 사이즈, 관심 거리 | **선택** (건너뛰기 가능) | 프로필 2단계 |
| 신발 | 지금 신는 러닝화 이름, 관심 신발로 저장한 제품 | 선택 | 신발 선택·저장할 때 |

- 브라우저 저장 공간에는 익명 로그인 상태와 서비스 설정이 저장됩니다.

## 법무·개인정보 담당자 검토 쟁점

| # | 쟁점 | 현재 사실 (코드·DB 기준) | 검토 요청 |
|---|---|---|---|
| L-1 | 신체 정보의 성격 | 키·체중·발 사이즈는 **선택 입력**(건너뛰기 가능). ITEMS 비교에만 쓰고 이벤트·PostHog로 보내지 않음 | 건강 관련 민감정보 해당 여부 · 해당하면 별도 동의 필요 여부 |
| L-2 | 항목별 처리 근거 | 익명 ID·테스트 결과·러닝 습관·러닝 기록 = 서비스 제공 / 신체 정보·신발 = 선택 / 이용 이벤트 = 통계 | 각 항목의 근거(동의 vs 서비스 제공 등)와 안내문 2번 문구 |
| L-3 | 고지 시점·위치 | 안내 화면은 프로필 2단계 링크와 주소 `/privacy`로만 열림. 첫 방문부터 익명 ID·이용 이벤트가 저장됨 | 첫 화면 이전 고지·동의가 필요한지, 모집 안내문(앱 밖) 고지로 충분한지 |
| L-4 | 국외 이전·처리위탁 | 3사 모두 미국 회사. DB 리전·Function Region은 콘솔 확인 대기. PostHog는 외부 참여자 데이터 미전송 | 국외 이전 고지·동의 필요 여부, 처리위탁 고지 항목 |
| L-5 | 연령 확인 | 앱 안 연령 확인 절차 없음. 참여자는 모집 단계에서 선별 | 모집 단계 확인으로 충분한지, 앱 안 확인 UI가 필요한지 |
| L-6 | 앱 접근 불가 시 삭제 요청 | 로그인 없음 → 이메일 요청자와 계정을 연결할 수단이 없음. 익명 ID(UUID)를 받아도 그 사람의 계정이라는 증명이 되지 않음 | 처리 방안(예: 보관 기간 만료 시 삭제 안내, 다른 확인 수단) 중 적법한 것 |
| L-7 | 법령상 보존 의무 | 결제·계약·회원 정보 없음 | 별도 보존 의무 여부 |
| L-8 | 로그·백업 | 제공업체 로그·백업이 앱 삭제와 별개로 남을 수 있음(기간은 콘솔·요금제 확인) | 안내문 3번 표현의 충분성 |
| L-9 | 설문 응답 | 설문은 앱 밖(구글 폼 등)에서 받음. 이름·연락처를 받지 않는 것이 기본 | 사례품 지급 등으로 연락처를 받으면 별도 고지가 필요한지 |
