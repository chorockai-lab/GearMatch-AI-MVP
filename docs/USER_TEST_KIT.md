## 2. 설문 최종안 (5분 이내, 익명)

이름·전화번호·이메일은 묻지 않습니다. 사례품 지급 등으로 연락처가 필요해지면 설문과 분리하고 별도 고지를 검토합니다(`PRIVACY_NOTICE_DRAFT.md` L-9).

| # | 질문 | 형식 |
|---|---|---|
| 1 | 러닝 동물 결과가 나와 얼마나 비슷했나요? | 1~5점 |
| 2 | 결과 설명 중 가장 공감된 부분 / 어색했던 부분은? | 주관식(선택) |
| 3 | 내 Runner를 완성하기까지 불편했던 단계가 있었나요? | 없음 / 테스트 / 러닝 습관 / 신체 정보 / 신발 선택 / 기타 (복수 선택) |
| 4 | 키·체중·발 사이즈를 입력했나요? 입력하지 않았다면 이유는? | 입력함 / 건너뜀 + 이유(선택: 귀찮아서 / 개인정보가 걱정돼서 / 필요성을 못 느껴서 / 기타) |
| 5 | 기간 동안 러닝 기록을 몇 번 남겼나요? 남기지 않았다면 이유는? | 0 / 1 / 2~3 / 4회 이상 + 이유(선택) |
| 6 | 이미지 저장을 해 봤나요? | 저장함 / 저장+공유함 / 안 해 봄 |
| 7 | (저장해 봤다면) 이미지를 SNS·친구에게 공유하고 싶은 정도는? | 1~5점 |
| 8 | ITEMS(신발 정보)를 봤나요? 도움이 됐나요? | 안 봄 / 1~5점 |
| 9 | 앞으로도 러닝을 기록하러 다시 들어올 것 같나요? | 1~5점 |
| 10 | 주로 어디서 열었나요? (모두 선택) | 카카오톡 / 사파리 / 크롬 / 삼성 인터넷 / 기타 |
| 11 | 사용한 휴대폰 | iPhone / Android / 둘 다 |
| 12 | 쓰는 중 기록이 사라지거나 처음부터 다시 시작된 적이 있나요? | 없음 / 있음 + 상황(선택) |
| 13 | 가장 좋았던 점 하나, 가장 아쉬웠던 점 하나 | 주관식 |

- 4번: 신체 정보 선택 입력에 대한 실제 반응(법무 검토 L-1 참고 자료).
- 10·11번: 브라우저별 익명 계정 분리로 생기는 중복 집계(한 사람 = 여러 사용자)를 보정합니다.
- 12번: 같은 브라우저 안 기록 유실(치명적 오류)을 참여자 쪽에서도 확인합니다.
