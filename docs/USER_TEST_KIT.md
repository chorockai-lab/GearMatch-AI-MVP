# 외부 사용자 테스트 준비 (러너 10~20명)

> 작성 2026-10-16 · 초안. 앱 기능·화면 변경 없이 쓰는 자료입니다. 측정은 Supabase `public.events` + `docs/ANALYTICS_QUERIES.md` (PostHog는 `qa` 모드라 참여자 데이터가 가지 않음).

## 1. 참여자 안내 (카카오톡으로 보낼 문구 초안)

> 안녕하세요! 러닝 성향을 동물로 알려 주는 **GearMatch** 테스트에 참여해 주셔서 감사합니다.
>
> 👉 링크: https://gear-match-ai-mvp.vercel.app
>
> 1. 링크를 열고 **5문항 테스트**(약 1분)로 나의 러닝 동물을 확인해 주세요.
> 2. 러닝 습관과 신발을 고르면 내 Runner가 완성돼요.
> 3. 테스트 기간 동안 달린 날은 **오늘의 러닝 남기기**로 기록해 주세요(거리·시간만).
> 4. 마음에 들면 **이미지 저장**으로 카드를 저장·공유해 보세요.
> 5. 기간이 끝나면 5분 설문을 부탁드릴게요.
>
> ⚠️ 로그인 없이 쓰는 서비스라 **처음 연 앱·브라우저에서만 기록이 이어집니다.** 카카오톡에서 열었다면 계속 카카오톡에서, 사파리·크롬에서 열었다면 계속 그 브라우저에서 열어 주세요. 브라우저 데이터를 지우면 기록을 되살릴 수 없어요.
> 개인정보 안내: 앱 안의 '개인정보 수집·이용 안내'를 확인해 주세요. 문의: [담당자 연락처 — 결정 필요]

- 링크에는 `?qa=1`을 **붙이지 않습니다**(붙이면 분석에서 제외됨).
- 테스트 기간(시작·종료 시각 KST)을 기록해 두면 아래 쿼리의 기간으로 씁니다.

## 2. 설문 초안 (5분 이내, 구글 폼 등 앱 밖에서)

| # | 질문 | 형식 |
|---|---|---|
| 1 | 러닝 동물 결과가 나와 얼마나 비슷했나요? | 1~5점 |
| 2 | 결과 화면의 설명(성향 분석·WHY) 중 가장 공감된 부분 / 어색했던 부분은? | 주관식(선택) |
| 3 | 처음 시작해서 내 Runner를 완성하기까지 불편했던 단계가 있었나요? | 없음 / 테스트 / 러닝 습관 / 신체 정보 / 신발 선택 / 기타 |
| 4 | 러닝 기록을 몇 번 남겼나요? 남기지 않았다면 이유는? | 0 / 1 / 2~3 / 4회 이상 + 이유(선택) |
| 5 | 이미지 저장을 해 봤나요? | 저장함 / 저장+공유함 / 안 해 봄 |
| 6 | (저장해 봤다면) 이미지를 SNS·친구에게 공유하고 싶은 정도는? | 1~5점 |
| 7 | ITEMS(신발 정보)를 봤나요? 신발 정보가 도움이 됐나요? | 안 봄 / 1~5점 |
| 8 | 앞으로도 러닝을 기록하러 다시 들어올 것 같나요? | 1~5점 |
| 9 | 주로 어디서 열었나요? | 카카오톡 / 사파리 / 크롬 / 삼성 인터넷 / 기타 |
| 10 | 가장 좋았던 점 하나, 가장 아쉬웠던 점 하나 | 주관식 |

- 9번은 브라우저별 익명 계정 분리 때문에 생기는 중복 집계(한 사람이 두 브라우저)를 보정하는 데 씁니다.

## 3. 지표 — 지금 측정 가능 vs 보완 필요

| 지표 | 측정 | 쿼리 (`docs/ANALYTICS_QUERIES.md`) | 비고 |
|---|---|---|---|
| 동물 테스트 완료율 | **가능** | §4(시작→완료), §5(문항별 이탈) | |
| 온보딩 완료율·단계별 이탈 | **가능** | §4(Reveal→온보딩 완료), **§9 추가**(습관·신체 정보·건너뛰기 세부) | |
| 첫 러닝 기록 저장률 | **가능** | §4(`pct_onboarded_to_first_run`), **§11 추가**(테스트 기간 기준) | |
| 이미지 저장·공유 | **부분 가능** | **§10 추가**(카드 종류·방식·결과별) | 앱은 "공유 시트 완료 / 다운로드 시작 / 길게 눌러 저장 안내 표시"까지만 앎 — 사진 앱 실제 저장·반응은 설문 5·6번 |
| ITEMS 방문·신발 관심 | **가능** | §8 | |
| 실제 재방문 | **가능 (같은 브라우저 안에서만)** | §7 | 다른 브라우저로 오면 새 사용자로 집계 |
| 재방문 의향 | 설문 | 설문 8번 | |

**공통 한계**: 익명 계정이 브라우저마다 따로라 "사용자 수 = 브라우저 수"입니다. 10~20명 규모에서는 설문 9번과 참여 인원으로 대조합니다.
**기간**: 쿼리의 `interval '7 days'` 대신 테스트 기간을 넣습니다(§9~§11 예시 참고).
